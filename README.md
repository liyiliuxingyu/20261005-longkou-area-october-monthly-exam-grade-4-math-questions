两张原卷照片位于 [originals](originals/)。试题和答案共用 LaTeX 题库，采用项目自带的 `examcn.cls`。在安装所需 TeX Live 组件后，在仓库根目录运行 `bash latex/build.sh` 即可编译两版 PDF。字体、许可证及编译依赖见 [LaTeX 工程说明](latex/README.md)。

课件内容、绘图脚本、123 幅公式矢量图及动画清单位于 [ppt_work](ppt_work/)。重新生成课件需要支持 `@oai/artifact-tool` 的环境，详细步骤见 [课件工程说明](ppt_work/README.md)。
